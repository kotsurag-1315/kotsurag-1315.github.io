# kotsurag-1315.github.io

## Раздел «Туры»

Анонсы поездок находятся в `assets/tours-data.js`. Для очередного обновления меняйте только нужную запись в этом файле: название, месяц, город, описание, фото и поля подробностей. Для названия, месяца, города и описания есть английские поля с суффиксом `En`; при заполнении подробностей на английском можно добавить такие же поля (`datesEn`, `priceEn` и т. д.). Порядок записей определяет порядок карточек; первая карточка открывается сразу. До подтверждения дат и цены оставляйте «Уточняются» / «Будет объявлена» и пометку о примерном анонсе.

Оформление находится в `assets/tours-page.css`, поведение раскрывающихся карточек — в `assets/tours-page.js`. Ссылки для связи ведут на `https://t.me/qitour_stuff`.

Перед переделкой раздела создана локальная Git-метка `backup-before-tours-2026-09-30` (исходный коммит `46eee3c`). Она сохраняет прежнюю версию без изменения каталога мест. После каждого согласованного обновления сайта стоит создавать отдельный коммит, чтобы можно было откатить именно его. Локальная метка сама по себе не является облачной резервной копией.
