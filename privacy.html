Какие данные и зачем используются

Для регистрации и входа используются email, идентификатор аккаунта, статус подтверждения почты, а при входе через Google — предоставленные имя и фотография профиля. Пароль обрабатывает Firebase Authentication. Для Premium используются идентификатор аккаунта и срок доступа.

При оплате email аккаунта передаётся ЮKassa вместе с суммой и описанием покупки. Сведения об оплате нужны для сверки платежа, ручной активации, выдачи чека и возвратов. Банковские реквизиты вводятся на странице платёжного сервиса, сайт KoreaMate их не собирает. Платёжный сервис обрабатывает данные по собственным условиям.

При обращении в поддержку используются адрес отправителя, текст и добровольно предоставленные сведения. Почта не используется для рекламной рассылки в рамках покупки доступа.

Хранение и внешние сервисы

Сайт размещён на GitHub Pages. Для аккаунтов и доступа используются Firebase/Google; база Cloud Firestore размещена в регионе europe-central2 (Варшава). Эти сервисы предполагают обработку данных за пределами России. KoreaMate не заявляет, что все данные хранятся в России. Поддержка работает через Gmail. При загрузке внешних ресурсов их поставщикам доступны технические данные запросов, включая IP-адрес.

Настройки языка, закладки и другие локальные настройки хранятся в браузере. Их можно удалить очисткой данных сайта; это не удаляет аккаунт Firebase. Сайт также использует Google Analytics для статистики посещений; сервис может получать технические сведения и идентификаторы браузера.

Основания и сроки обработки

Данные, необходимые для аккаунта, оплаты и предоставления доступа, обрабатываются для исполнения договора; сведения для чеков и обязательного учёта — для выполнения требований закона. Когда для иной обработки требуется согласие, оно должно запрашиваться отдельно. Принятие оферты не является согласием на рекламную рассылку.

Данные хранятся в течение срока, необходимого для соответствующей цели: обслуживания аккаунта и доступа, разрешения обращения или исполнения обязательного требования закона. По достижении цели данные подлежат удалению или обезличиванию, если отсутствует иное законное основание хранения. Локальные данные остаются в браузере до их очистки.
